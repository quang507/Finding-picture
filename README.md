# Finding-picture — Tìm Hình Quang

App Streamlit tìm ảnh theo nội dung/phong cách/thành phần bằng CLIP + FAISS + YOLO.
Dùng để tìm kiếm nhanh trong kho ~10.000 file ảnh stock trên máy.

```bash
streamlit run app.py
```

> Project **Học Ngôn Ngữ Ký Hiệu VSL** (trước nằm trong `vsl-web/` + `training/`)
